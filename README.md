# Fábrica Ocarina — Mini webs comerciales

V1 funcional de una fábrica privada para producir muchas mini-webs desde un mismo lugar.

Flujo: Negocio → Catálogo → Diseño → Vista final → Exportar.

No usa servidor, base de datos ni dependencias externas. Guarda el borrador en el navegador y exporta una página HTML independiente compatible con GitHub Pages.

Principio: mucho sistema por detrás, muy poco que aprender por delante.
